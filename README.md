# Leonida Cover Studio — Pembuat Cover Art ala GTA 6

![Rank](https://make.fun/badge/gta6-cover-art-01/Dedypol22/gta6-cover-art-entry/rank.svg)
![Reward](https://make.fun/badge/gta6-cover-art-01/Dedypol22/gta6-cover-art-entry/reward.svg)

**Leonida Cover Studio** adalah aplikasi web statis untuk membuat cover art gaya poster GTA 6 menggunakan foto Anda sendiri.

## Fitur Utama
- **Multi-panel Layout:** Pilih antara layout Trio, Duo, atau Solo.
- **Custom Foto:** Unggah foto lokal atau gunakan foto contoh.
- **Editor Presisi:** Geser dan zoom foto di setiap panel dengan mudah.
- **Tipografi Ikonik:** Caption dengan outline tebal dan drop shadow khas poster game.
- **Grade Warna:** Pilihan filter Sunset, Neon, dan Malam Leonida.
- **Ekspor PNG:** Mendukung ukuran post populer (1080x1080, 1080x1350, 1920x1080).

## Cara Menjalankan
Aplikasi ini berjalan sepenuhnya offline dan tidak memerlukan koneksi internet.

1. Pastikan Anda memiliki Node.js terinstal.
2. Jalankan server lokal:
   ```bash
   node serve.ts
   ```
3. Buka `http://localhost:8080` di browser Chrome Anda.
